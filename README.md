# Joshua Nelson — Flutter Portfolio

An interactive portfolio showcasing mobile and desktop applications built with
Flutter and Dart. Each project includes an App Store-style screenshot gallery,
a concise product overview, and the technologies used to build it.

## Highlights

- Responsive Flutter Web interface
- Interactive project showcase pages
- Mobile and desktop screenshot presentations
- Projects using Firebase, Supabase, REST APIs, WebSockets, Stripe, and OpenAI
- Automatic deployment to GitHub Pages

## Run locally

```sh
flutter pub get
flutter run -d chrome
```

## Verify

```sh
flutter analyze
flutter test
flutter build web --release
```

## Built with

- Flutter
- Dart
- Material Design
